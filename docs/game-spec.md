# ゲーム仕様書(現行挙動のリファレンス)

> **目的**: リファクタリング時の「挙動維持」の判定基準。ここに書かれた数値・ルールを変えてはならない。
> 仕様書とコードが食い違う場合は**コードの挙動が正**(本書を修正すること)。
> **最終更新**: 2026-07-05(コミット 5d46eee 時点のコードから起こした)

## 1. 基本構造

- 論理座標系: `0..832`(= 52マス × 16px)。グリッドは `mapGrid[y][x]`、`y, x ∈ 0..52`(53×53)。
- 画面: 1920×1080 固定の PIXI キャンバスを CSS で 16:9 レターボックス表示。
- アイソメトリック変換(`toIso`): 中心 (416, 416) → 画面 (960, 540)、`SCALE_X=2.0`, `SCALE_Y=1.0`。
- ゲーム状態 `status`: `title` | `playing` | `paused`(コンテキストメニュー表示中) | `gameover`。

## 2. タイルコード(mapGrid の値)

| コード | 地形 | 移動速度倍率 | A*コスト |
|---|---|---|---|
| 0 | 草地 | 1.0 | 1.0 |
| 1 | 水 | 0(侵入不可)/ Rank3のみ 0.5 | Infinity / Rank3のみ 2.0 |
| 4 | 橋 | 1.0 | 1.0 |
| 21, 22 | 低山 | 0.5 | 2.0 |
| 23, 24 | 高山(四方を山に囲まれた山) | 0.35 | 2.86 |
| 31–33 | 木・疎 | 0.85 | 1.18 |
| 34, 35 | 木・密 | 0.7 | 1.43 |

- 生成中の中間コード: 2=山(未バリアント), 3=木(未バリアント)。バリアント割当後は 21-24 / 31-35 のみが残る。
- 拠点の支配領域内では地形ペナルティが 50% 軽減: `mult = mult + (1.0 - mult) * 0.5`。

## 3. マップ生成(シード決定的)

1. シード: 6桁数字文字列(未指定ならランダム生成)。`hashString` で数値化し **mulberry32** PRNG を初期化。
   以降のすべての乱数はこの PRNG から消費される。**消費順序を変えると同一シードで別マップになる。**
2. 地形: FBM ノイズ2系統(標高 e、湿度 m)。`e > 0.45` → 山、`m > 0.3` → 木、他 → 草。
3. 川: 1〜2本。画面端から端へノイズで蛇行させて彫る。1/3 の確率で分岐。
4. 橋: 川ごとに 2〜4 本。直線状の川で両岸が陸のセルにのみ架け、周囲の候補点を除去して密集を防ぐ。
5. 陸地接続: 広さ20超の陸地が川で分断されていたら、最近接の海岸線2点間に Bresenham で橋を通す(最大10回試行)。
6. 拠点配置(すべて周囲3×3に水/橋がなく、既存拠点から100px以上離れた位置):
   - プレイヤー本拠地: 左下 (48, 784) 付近から探索
   - CPU本拠地: 右上 (784, 48) 付近から探索
   - 固定中立砦(Rank2, 初期production 50): 左上 (100,100) 付近と右下 (732,732) 付近
   - 追加中立砦: 0〜2個(Rank2, production 50)
   - 中立集落: 8〜14個(Rank1, production 10)
7. 拠点周囲 5×5 マスを草地化(川と橋は消さない)。

## 4. 拠点(Base)

| Rank | 建物 | cap | growth(/秒) | アップグレード費用 |
|---|---|---|---|---|
| 1 | 集落 | 100 | 2.0 | 80 |
| 2 | 砦 | 150 | 3.0 | 120 |
| 3 | 城 | 999 | 4.5 | —(不可) |

- 本拠地(isCore)は見た目が城。所有者初期 production は 20、中立集落は 10、中立砦は 50。
- 生産: 非中立拠点のみ `production += growth * dt`(cap 上限)。
- **支配領域(zone)**: 半径 75〜150px、`production / cap` に比例。イージング速度 2.0(指数緩和)。
  - 昼のCPU領域は ×0.65、夜のプレイヤー領域は ×0.75。中立は 0。
- 占領: production が 0 を割ると所有者交代。超過分が新 production。**中立を占領した場合は Rank 維持**、敵拠点を占領した場合は Rank1 にリセット。
- アップグレード: `production >= upgradeCost` で実行可能。費用を差し引いて Rank+1。

## 5. ユニット(Unit)

- 送軍: `floor(source.production * sendRatio)`(1未満なら送らない)。source から差し引く。Rank は source の Rank を継承。
- 基本速度 `UNIT_SPEED = 30` px/秒。実効速度 = 30 × 地形倍率 × 時間帯倍率 × ランク倍率。
- Rank3(金)特典: 移動 ×1.1、攻撃 ×1.1、水上移動可(×0.5)。
- 経路: A*(8方向、斜め1.414)。見つからなければ直線。同方向の中間点は簡略化。
- **自然減衰**: 出発1秒後から `1.0 × ランク減衰率 × 地帯倍率 × 時間帯倍率` /秒。
  - ランク減衰率: Rank1=1.0, Rank2=1.1, Rank3=1.2
  - 地帯倍率: 味方領域内=0(減衰停止)、敵領域内=2.0、中立地帯=1.0
- **戦闘(ユニット同士)**: 敵ユニットと距離12px未満で交戦状態に。互いに毎秒 10(Rank3は11)ずつ power を削る。相手消滅で解除。
- **追跡**: 非交戦時、距離50px未満の敵ユニットを発見すると追跡(経路を離れて直進)。
- **到着**: 最終ウェイポイント到達で対象拠点と解決 — 味方なら production 加算(cap上限)、敵/中立なら減算(0割れで占領)。
- power ≤ 0 で消滅。`stopUnit` で待機(その場停止)、`redirectUnit` で目的地変更(経路再計算)。

## 6. 昼夜サイクル

- `dayTime`: 0〜1439(分)。**実時間1秒 = ゲーム内30分**。開始は常に 360(6:00)。
- 昼 = 6:00〜18:00(360〜1080)。
- 補正(不死者テーマ: プレイヤーは夜が得意、CPUは昼が得意):

| 対象 | 移動速度 | 減衰 | 支配領域 |
|---|---|---|---|
| 昼の CPU | ×0.6 | ×1.5 | ×0.65 |
| 夜のプレイヤー | ×0.75 | ×1.3 | ×0.75 |

- 画面の夜間表現(`getNightAlpha`): 6:00〜17:00 = 0、17:00〜18:00 で 0→0.5 へ遷移、18:00〜翌5:00 = 0.5、5:00〜6:00 で 0.5→0 へ遷移。
- 夜間 tint(`getNightTint`): R,G を `1 - alpha*0.9` 倍、B を `1 - alpha*0.5` 倍。マップ・拠点・ユニット・背景に適用(UIテキストは対象外)。

## 7. CPU AI

- 思考間隔: 0.5〜1.5秒のランダム(`Math.random()` — シード非依存で良い)。
- 送軍元: CPU拠点からランダムに1つ選択。優先順位:
  1. 本拠地防衛: CPU本拠地の production が cap の30%未満なら本拠地へ送軍
  2. 最寄りの中立拠点へ
  3. 最寄りのプレイヤー拠点へ
  4. どれも成立しなければ、`production >= upgradeCost + 20` でアップグレード
- 送軍判定(`tryCPUSend`): 送軍量 = production の50%。敵対拠点には `target.production + 5` 以上が必要。さらに A* 経路長から到着時 power を見積もり、`target.production * 0.5`(味方なら1)を下回るなら中止。

## 8. 操作(入力)

- **ドラッグ送軍**: 自拠点を押下 → ドラッグ → 対象拠点(40px以内)で離す。A*経路の緑矢印プレビュー表示。
- **ダブルクリック(300ms以内)**: 対象拠点へ全自拠点から一斉送軍(マウスが対象から30px離れるとキャンセル)。
- **長押し(500ms、移動10px未満)**: コンテキストメニュー表示 + ゲーム一時停止。
  - 拠点: アップグレード(費用表示、不足時 disabled)
  - ユニット: 待機
- **ユニットクリック**: 選択トグル。選択中は経路線と目的地ハイライト表示。自ユニットはドラッグで目的地変更(`redirectUnit`)。
- 背景クリックで選択解除。メニュー外クリックでメニュー閉鎖 + 再開。

## 9. UI / 画面要素

- **タイトル画面**(PIXI実装): 背景画像 + ビネット + 血色オーバーレイ、グラデーションロゴ、火の粉パーティクル40個、「覚醒する」ボタン(ホバーで光筋)、「特定の運命(SEED)で開始」(`window.prompt` で6桁入力)。開始時 1000ms フェードアウト。
- **時刻表示ウィジェット**(右上、PIXI実装): 時間帯別の空テクスチャ(Denzi100225-4.png から切出し、毎時45分かけてクロスフェード)、太陽(12:00南中)/月(0:00南中)が楕円軌道を周回し地平線 y=60 のマスクで沈む。石造りレリーフ枠(黒背景を透過処理)。
- **SEED表示**: 左上。**Send Ratio スライダー**: 画面下中央、10%〜90%を10%刻み。
- **ゲームオーバー**: 本拠地(isCore)を失った側の負け。DOM モーダルで Victory!/Defeat... + Restart / Back to Title。
